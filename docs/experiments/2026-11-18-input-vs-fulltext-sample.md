# 표본 대조: 제목·요약문만으로 만든 이슈 문장은 기사 본문과 어긋나는가

- 대상: 운영 서버의 2026-11-18 21:03 실행 결과(`pipeline_run` id 4). 종목 10개, 기사 47건, "주요 이슈" 문장 22개.
- 분석 모델: `gemini-3.5-flash-lite` (체인의 예비 모델. 이 실행 시점에는 서버 환경 파일에 Anthropic 키가 없었고, 체인은 키가 없는 제공자를 건너뛴다. 키를 넣고 재시작한 다음 실행(id 5)에서는 Claude Haiku 가 응답했다).
- 프롬프트: 수치 인용 지침이 들어간 운영 프롬프트.

## 왜 했나

이 서비스는 네이버 검색 API 가 주는 **기사 제목과 요약문**만 모델에 넣는다. 기사 본문은 읽지 않는다.
이번 수집분 47건의 요약문은 109~139자(중앙값 126자)이고 47건 모두 "..." 로 잘려 있다.
그래서 "앞 100여 자만 보고 쓴 문장이 본문과 어긋나지 않는가"를 표본으로 확인했다.

## 방법

1. 기사 47건의 원문 링크를 열어, 요약문이 기사의 어느 부분인지와 제목+요약문만으로 핵심 사실을 알 수 있는지 판정했다.
2. 이슈 문장 22개를 두 가지로 판정했다.
   - 입력 대비: 인용한 기사의 제목+요약문만으로 문장이 뒷받침되는가.
   - 본문 대비: 인용한 기사의 본문과 어긋나지 않는가(본문을 연 경우만).
3. 1차 판정은 AI 평가자(Claude Sonnet) 한 명이 했다. "뒷받침됨·일치"가 아닌 항목 5개는 작업 세션이 입력 원자료와 원문을 다시 열어 확인했다.

## 대조 중에 찾은 다른 문제: 종목 귀속 오류

종목 "에스엠"(엔터테인먼트)의 기사 5건 중 3건이 다른 회사 "에스엠벡셀"(기사에 "배터리 제조기업"으로 적힘)의 기사였다.
이슈 문장도 에스엠 종목 아래에 에스엠벡셀의 군용 배터리 공급계약을 썼다. 문장은 인용 기사와 일치하므로 위 판정으로는 잡히지 않는다.
원인은 관련성 필터가 "제목에 종목명이 들어 있는가"만 보는 것이다(`NewsService.parseNews`).
같은 날 필터를 고쳤다. 종목명 뒤에 다른 글자가 이어지는 제목은 다른 단어로 보고 제외한다(조사와 일부 접미 표현은 허용). 같은 47건에 규칙을 적용하면 에스엠벡셀 3건과 하이브재팬 1건이 제외된다. 근거와 부작용은 `docs/ARCHITECTURE_DECISIONS.md` 2번 절에 있다.

요약문이 사진 설명인 기사 1건(SK하이닉스 2번)은 원문에서 사진 출처 표기가 붙은 설명문임을 확인했다. 이 기사에서 모델이 가진 정보는 사실상 제목뿐이다.

## 같은 날 주 모델(Claude Haiku 5.5) 결과로 한 번 더

서버에 Anthropic 키를 넣고 재시작한 뒤의 실행(21:38, `pipeline_run` id 5, 분석 모델 `claude-haiku-5-5`)을 같은 방법으로 대조했다.
두 실행 모두 저장된 기사는 47건이고 링크 기준으로는 46건이다(한 기사가 두 종목에 걸려 있다). 그 46건 중 43건이 앞 실행과 같은 기사다. 같은 기사의 기사별 판정은 앞의 것을 다시 썼고, 이슈 문장은 앞 판정을 보지 않고 새로 판정했다.

| 이슈 문장 | 예비 모델 gemini-3.5-flash-lite (21:03) | 주 모델 claude-haiku-5-5 (21:39) |
|---|---|---|
| 문장 수 | 22 | 28 |
| 입력 대비 뒷받침됨 | 20 | 25 |
| 입력 대비 일부만 | 2 | 3 |
| 입력 대비 뒷받침 안 됨 | 0 | 0 |
| 본문 판정이 가능했던 문장 | 13 | 20 |
| 본문과 일치 | 10 | 16 |
| 맥락 누락 | 3 | 4 |
| 본문과 불일치 | 0 | 0 |
| 다른 회사를 다룬 문장 | 1 | 1 |
| 실행 이력의 숫자 총수 / 확인 안 된 숫자 | 48 / 4 (4개 모두 표기 차이) | 41 / 0 (이 실행 한 번의 값. 다음 실행 id 6 은 48 / 2) |

Haiku 의 "일부만" 3개(입력 원자료로 재확인):

| 종목 | 내용 |
|---|---|
| SK하이닉스 | 요약문은 "본예산 6조원 시대", "올해 당초예산(3조7904억원)보다 58.9% 불어난..." 에서 잘렸다. 문장은 "올해 본예산 6조원"이라고 써서 연도를 입력에 없는 쪽으로 붙였다. |
| 삼성전자우 | 요약문은 "미래에셋증권에서 거래하는 고수익 투자자들이 18일 오전"인데 문장은 이 한정을 뺐다. 시장 전체 이야기로 읽힌다. |
| 하이브 | 요약문 첫 문장 "올해 3분기 새로 쓴 기록이다"가 무엇을 가리키는지 잘려 있는데, 문장은 누적 매출을 그 기록으로 이었다. |

Haiku 의 "맥락 누락" 4개: 영업이익 감소의 비교 기준(전분기 대비)이 빠짐, MLCC 협력의 단계가 빠짐(경계 사례), 두산에너빌리티 지원 규모가 빠짐, 키홀더 인수가 지분 50.1% 취득 예정이라는 점이 빠짐. 뒤의 세 개는 예비 모델에서도 같은 기사에서 나온 누락이다.

두 실행에서 달라진 문장(같은 기사, 직접 비교):
- 삼성전기: 예비 모델은 주어를 엔비디아 하나로 썼고, Haiku 는 "삼성전기와 엔비디아는"으로 기사와 같게 썼다.
- 두산에너빌리티: 예비 모델은 요약문의 "추가 자금 조달은 불투명"을 뺐고, Haiku 는 별도 문장으로 썼다.

**두 모델의 비율은 약 90%로 비슷하다(20/22, 25/28). 문장 수가 적어 어느 모델이 더 낫다고 말할 수 없다.** 두 평가는 같은 종류의 AI 평가자가 따로 수행했고, 어느 모델의 문장인지 가리지 않았다.

## 이 결과로 말할 수 있는 것과 없는 것

말할 수 있는 것:
- 이번 표본에서 이슈 문장 22개 중 20개는 인용한 기사의 제목·요약문으로 뒷받침됐다. 나머지 2개는 주체가 바뀌었거나 잘린 요약문에서 추론한 것이다.
- 본문을 확인할 수 있었던 13개 중 본문과 어긋난 문장은 찾지 못했고, 3개는 중요한 조건이 빠져 있었다.
- 읽을 수 있었던 기사 31건 중 26건은 제목+요약문만으로 핵심 사실을 알 수 있었다.

말할 수 없는 것:
- "본문과 어긋나는 문장이 없다." 9개는 본문을 열지 못해 판정하지 못했다. 네이버 뉴스 링크 9건은 통째로 빠졌다.
- "기사를 요약한다", "원문과 대조해 검증한다." 서비스는 본문을 읽지 않는다. 이 대조는 일회성 표본 확인이다.
- "Haiku 가 예비 모델보다 본문에 충실하다." 두 모델의 비율이 비슷하고 표본이 작다.
- 위의 "말할 수 있는 것" 세 줄은 예비 모델 표본의 숫자다. 주 모델 숫자는 바로 위 표를 쓴다.

## 한계

- 같은 날 두 시점, 문장 22개와 28개, 기사는 실행마다 47건(대부분 같은 기사).
- 1차 평가자는 AI 한 명이고 사람이 전수 확인하지 않았다.
- 원문은 웹 페이지를 요약해 주는 도구를 거쳐 읽었다. 본문 전체를 직접 읽은 것이 아니어서 수치 일부에 오류가 있을 수 있다.
- 평가자와 재확인 모두 Anthropic 모델이다. 예비 모델 표본의 판정 대상은 Google 모델의 출력이고, 주 모델 표본의 판정 대상은 같은 회사(Anthropic) 모델의 출력이다. 같은 회사 모델끼리의 평가가 판정을 후하게 만들었는지는 확인하지 않았다.

## 원자료

판정 대상 스냅샷과 항목별 판정은 저장소에 넣지 않았다(기사 제목·요약문·링크가 들어 있다). 작업 세션의 임시 폴더에 있으며 재현하려면 `GET /api/stocks/top10`, `GET /api/stocks/{id}/news` 로 같은 형식의 자료를 다시 받을 수 있다.
